Ремесленный хлеб — обновление по макету Figma от 6 ноября 2026.

1. Распакуйте архив и откройте index.html в браузере.
2. Для обновления GitHub Pages загрузите index.html и папку assets в корень репозитория Bread, заменив прежние файлы. Сам ZIP загружать в репозиторий не нужно.

HTML содержит стили, скрипты и Nexa Script; остальные шрифты и изображения находятся в assets.
Этапы выпечки переключаются при прокрутке. На коротких экранах и при уменьшении анимации показываются последовательно.
Таймер учитывает 15:00 по Москве. Оформление заказа, видеоролик и переход в приложение пока не подключены.
В блоке хранения оставлены серые поля из макета. Финальный заголовок перенесён буквально: «Пусть дома / ещё по дороге домой.».
Визуальная проверка в браузере недоступна из-за отсутствия сервиса предпросмотра.
